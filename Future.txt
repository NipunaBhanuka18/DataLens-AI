Track 1: The "Magic" Interaction (Data Chat)
This track is all about the demo. When people see this on LinkedIn, it immediately proves the tool isn't just a wrapper; it's a thinking engine.

Tier 1 (Portfolio/LinkedIn Magnet): Chat-to-Chart. Add a command bar (like Apple's Spotlight or Raycast). The user types: "Show me the correlation between Age and Income," and the LangGraph agent dynamically generates a new Plotly chart on the screen instantly. This records beautifully for a 30-second LinkedIn video demo.

Tier 2 (Pro Extension): Natural Language SQL & Live DBs. The free tier only works on the uploaded CSV. The Pro version allows users to connect their live PostgreSQL or Snowflake databases, and the chat agent writes and executes the SQL to generate the charts in real-time.

Track 2: The Deliverable (Reporting)
People love taking credit for AI's work. Giving them a beautiful artifact they can share with their boss is a massive growth loop.

Tier 1 (Portfolio/LinkedIn Magnet): One-Click "Data Story" PDF. Use @react-pdf/renderer to generate a gorgeous, perfectly formatted executive summary document containing the Health Score, the agent's insights, and the charts. Add a subtle "Generated by DataLens AI" watermark. When users share these PDFs internally, it drives traffic back to you.

Tier 2 (Pro Extension): Export to Jupyter Notebook. Pro users (data scientists and engineers) don't just want the PDF; they want the code. This feature exports the exact Polars python code the AI used to calculate the stats into a .ipynb file so they can continue working on it locally.

Track 3: The Persona (Gamification & Tone)
Data is usually boring. Injecting personality into the AI makes the tool highly shareable on social media.

Tier 1 (Portfolio/LinkedIn Magnet): "Roast My Dataset" Mode. Add a toggle that changes the LangGraph Insight Agent's system prompt from "Professional" to "Ruthless." It roasts the user for having missing values or terrible data collection practices. Developers love sharing their "roasts" on Twitter and LinkedIn.

Tier 2 (Pro Extension): Custom AI Personas & White-labeling. When managing deliverables and handling payments for your independent software business, you can use this tier to deploy custom-branded versions of the dashboard. You strip the DataLens branding, inject your client's logo, and tune the AI to speak in their specific corporate tone. It transforms the tool into a premium upsell for your software services.



📦 The Feature Matrix: Base vs. Pro
🟢 BASE TIER (The Portfolio & Lead Magnet)
Goal: Maximum virality, zero-friction user experience, and visual "wow" factor for LinkedIn demos.

Currently Implemented:

The Polars Engine: Sub-second parsing of 500k+ row datasets (Zero Raw Data Strategy).

Dataset Health Score: Deterministic scoring (Completeness, Consistency, Uniqueness).

Basic EDA Agent: Descriptive statistics (skewness, outliers, distribution).

macOS-Grade UI: Glassmorphism, TanStack Table preview, Framer Motion transitions.

Chat-to-Chart: Raycast-style command bar for instant Plotly generation.

One-Click PDF: Watermarked executive summary export.

Persona Engine: Professional, Executive, and the viral "Roast My Dataset" mode.

Missing & To Be Added (Base Tier):

Automatic ML Problem Detection: The AI instantly detects if the dataset is meant for Classification, Regression, Clustering, or Time Series without the user telling it.

Chart Justification: Adding a "Why this chart?" tooltip to visualizations (e.g., "Histogram selected because Age is numerical and moderately skewed").

The Data Story: Restructuring the Insights panel to flow logically: Quality → Interesting Pattern → Possible Cause → Business Impact.

🔵 PRO TIER (The DS Consultant SaaS)
Goal: Deep machine learning readiness, actionable reasoning, and enterprise-grade deliverables.

Currently Implemented:

(None yet—everything built so far has been descriptive. Pro tier is all about reasoning.)

Missing & To Be Added (Pro Tier):

Advanced DS Math Engine: VIF (Multicollinearity), Mutual Information (predictive power), and Normality Tests (Shapiro/KS).

Modeling Readiness Score (0-100): A separate score evaluating if a model can actually learn from the data (evaluating class imbalance, dimensionality, etc.).

Feature Leakage Detection: Flagging columns that give the model the answer before it predicts it.

AI Preprocessing Recommendation Engine: The core "Consultant" upgrade. Actionable steps (e.g., "Use median imputation," "Apply Standard Scaler") with strict reasoning.

Algorithm Recommender: Advising on model selection (e.g., "Use Random Forest instead of XGBoost because of low row count").

Confidence Scoring: Tagging every AI insight with a mathematical confidence percentage (e.g., "Strong relationship [92% Confidence]").

Jupyter Notebook Export: Compiling the AI's recommendations into a .ipynb file with the actual Python code needed to execute the preprocessing.
