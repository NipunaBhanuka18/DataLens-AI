🚀 DataLens AI: Project Architecture & Feature Log
Product Overview: An autonomous, full-stack AI Data Science Copilot that transforms raw datasets into actionable insights, interactive visualizations, and executive narratives using deterministic math and LangGraph agents.

🟢 BASE TIER (Fully Implemented)
Objective: Deliver sub-second processing, deep statistical extraction, and a highly visual, portfolio-ready macOS-grade user experience.

Decoupled FastAPI Backend: An asynchronous Python server that strictly separates file ingestion streams from heavy mathematical processing.

Polars Aggregation Engine: Sub-second parsing and statistical extraction capable of handling 500,000+ row datasets without RAM bottlenecks.

Deterministic Health Score: A rigorous 0-100 dataset scoring algorithm evaluating Completeness (40%), Consistency (30%), and Uniqueness (30%).

Automated EDA Profiling: Exact calculations of 3-sigma outliers, numerical skewness, variance, and high-cardinality categorical flags.

LangGraph Multi-Agent Pipeline: A sequential StateGraph routing metadata through specialized nodes (Quality, EDA, Visualization, and Insight).

The Data Story: A structured 4-part narrative output generated by the Insight Agent (The Data Quality Reality, The Core Pattern, The 'Why', and Business Impact).

Chart Justification: AI-generated explanations rendered as tooltips on the frontend detailing exactly why a specific Plotly chart was selected.

Next.js 15 macOS UI: A premium frontend utilizing backdrop-blur glassmorphism, soft drop-shadows, and Framer Motion stagger-fade transitions.

TanStack Data Preview: An interactive, sortable preview table for viewing schema data types and the first 50 rows prior to analysis.

Intelligent Pipeline Steppers: Dynamic loading UI that communicates exact backend operations to the user in real-time.

Chat-to-Chart (Command Palette): A global Cmd+K command bar that takes natural language queries and instantly renders custom AI Plotly charts inside a centered modal.

One-Click Executive PDF Export: Client-side generation compiling the Health Score, narrative insights, and high-res chart snapshots into a branded report.

Dynamic Persona Engine: On-the-fly LLM tone switching (Professional, Executive, Roast Mode) without needing to re-run backend math aggregations.

🧠 ARCHITECTURAL & ENGINEERING JUSTIFICATIONS
Objective: Ensure enterprise-grade scalability, security, and fallback reliability.

Zero Raw Data Strategy: The raw CSV rows never leave the server. Only aggregated Pydantic metadata schemas are sent to the LLM. Justification: Ensures strict data privacy, drastically lowers LLM token costs, and enables massive scale.

Polars over Pandas: Utilizing Polars and fastexcel. Justification: Multi-threaded Rust execution provides superior memory efficiency and speed for large datasets.

Deterministic CI/CD Fallback: A rule-based insight generator that kicks in if the LLM API fails. Justification: Guarantees automated tests, local development, and the frontend UI never break due to third-party rate limits.

Stateless File Management: Uploads stream to a /tmp directory. Justification: Makes the Docker container fully compatible with ephemeral cloud environments (Render, Railway) while preventing local disk bloat.

Gunicorn + Uvicorn Workers: The production entry point utilizes a process manager. Justification: Prevents the FastAPI server from crashing under concurrent, heavy dataset uploads.

🔵 PRO TIER (Future Implementation Roadmap)
Objective: Transition from descriptive analytics to an active "AI Data Science Consultant" focusing on Machine Learning readiness and actionable reasoning.

Advanced DS Math Engine: Implementing scikit-learn and scipy to calculate Variance Inflation Factor (VIF), Mutual Information (predictive power), and Shapiro-Wilk/KS normality tests.

50,000-Row Sampling Guard: A programmatic limit prior to heavy scipy calculations to ensure the API response remains under 3 seconds.

Modeling Readiness Score: A secondary 0-100 metric evaluating algorithmic viability by penalizing target imbalances, feature leakage, and the curse of dimensionality.

Automatic ML Problem Detection: The AI automatically categorizes the dataset for Classification, Regression, Clustering, or Time Series without user input.

The DS Consultant Agent: A new LangGraph node utilizing .with_structured_output() to output actionable preprocessing steps (e.g., specific imputation methods or standard scaling) based on mathematical heuristics.

Algorithm Recommender: Advising on baseline machine learning model selection based on dataset shape and non-linear feature interactions.

Confidence Scoring: Appending calculated mathematical confidence intervals (e.g., 92%) to LLM-generated claims.

Jupyter Notebook Export: Compiling the AI consultant's preprocessing recommendations directly into an executable .ipynb Python script.
